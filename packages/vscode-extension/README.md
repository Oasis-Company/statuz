# Statuz VS Code Extension

VS Code Extension for Statuz AI Agent Runtime Status Protocol.

## Features

- Initialize Statuz workspace
- Validate Statuz files
- Resume from current state
- Manage niche signals, assessments, and SYN decisions

## Getting Started

1. Press `F5` to open a new window with your extension loaded.
2. Run your command from the command palette by pressing (`Ctrl+Shift+P` or `Cmd+Shift+P` on Mac) and typing `Statuz: Hello World`.
3. Set breakpoints in your code inside `src/extension.ts` to debug your extension.
4. Find output from your extension in the debug console.

## Commands

- `Statuz: Hello World` - Welcome message
- `Statuz: Initialize Statuz` - Initialize Statuz in current workspace
- `Statuz: Validate All Files` - Validate all Statuz and niche files
- `Statuz: Resume from Statuz` - Resume from current statuz.yaml state
