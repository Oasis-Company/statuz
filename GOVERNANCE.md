# Governance

Statuz is maintained under Oasis Company.

## Project goals

- Establish a clean protocol category: AI Agent Runtime Status.
- Keep the 0.1 format simple and useful.
- Grow through real integrations, not abstract complexity.

## Decision process

Major changes to the protocol should be proposed as issues or ADRs.

A change is major if it:

- changes required fields;
- changes compatibility behavior;
- introduces network protocol assumptions;
- changes the definition of Statuz from status to memory.

## Compatibility

0.x versions may change, but migrations should be documented.
