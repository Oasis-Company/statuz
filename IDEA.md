# Statuz

Let AI truly know where it is, what it's doing, and why it all matters.

---

## The Problem

The current paradigm of AI collaboration has a fundamental flaw: with every new session, the agent rebuilds its understanding of the world from near zero. RAG, long context windows, vector memory — all mainstream approaches share the same assumption — that the agent knows what to ask for. But the defining difficulty of genuine creative work, long-horizon engineering, and zero-to-one exploration is precisely this: the agent doesn't know what it doesn't know.

Documents are static. Context is a consumable. Information is passively retrieved. Every session switch is a "compression soup" — the project's structure, intent, and ecological niche diluted to a faint outline. No matter how many times the user explains, the agent always treats it as an ordinary task.

This is not a window-size problem. This is a cognitive-architecture problem.

## The Conviction

Information should not be passively retrieved — it should be actively released, like working memory in the human brain.

We believe the answer is not a larger context window, but an externalized, persistent, structured model of "what's going on right now" — one the agent inhabits rather than reads. This model doesn't store content; it stores topology: what relates to what, what changed recently, what matters at this moment.

Topology, semantics, and cyclic patterns — the union of these three is what makes true human-AI synergy possible.

## The Vision

Statuz is a **persistent, cross-tool dependency-graph engine** that gives AI agents state awareness. It is not a bigger memory — it is a better index, one that lets the agent always know its position, the meaning of its task, and the place of its work within the larger ecosystem.

Three pillars:

- **Better Engine** — a reliable, content-addressed topological foundation where structural facts are always trustworthy.
- **Better Diagram** — an attention-ranked working view, where agents and humans see the evaluated graph, not the raw one.
- **Better Loop** — an incremental, multi-rate signal propagation mechanism that lets state changes ripple outward like waves, rather than requiring a full refresh.

## The North Star

**Context-recovery cost**: the number of tool calls (or tokens) an agent needs, after a session boundary, to reach a state where it can work effectively.

This is the only metric Statuz cares about. Engine performance, storage efficiency, compression ratio — these are means, not ends. What we truly measure is whether the agent loses the shape of a task between sessions.

## The Creed

- Structure is fact. It never decays. Only attention decays.
- Information is not pulled into context — it is released into view.
- An agent is not an isolated reasoner, but a participant in an ecosystem.
- Control should return to the user and the project — not be left to the randomness of a context window.
