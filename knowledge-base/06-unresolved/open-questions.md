## 一、编译与环境问题

### 1.1 Cargo Build/Check 失败（sandbox 限制）

**问题**：sandbox 环境中 `link.exe` 无法写入 `%TEMP%`，导致 `cargo check` / `cargo build` 失败。

**影响**：无法在生产环境中验证编译。所有代码变更只能通过语法检查和自测逻辑验证。

**缓解**：
- 本地开发时已验证通过（`cargo build` 成功）
- CI 配置 `.github/workflows/ci.yml` 保留，但未在 sandbox 中测试

**待解决**：无。这是一个 sandbox 环境限制，不是代码问题。

## 二、存储与序列化问题

### 2.1 加密/压缩未实现

**问题**：`flags` 字段的 `FLAG_COMPRESSED`（0x0001）和 `FLAG_ENCRYPTED`（0x0002）位是占位符，未实现真实的压缩（zstd）和加密（chacha20）。

**状态**：Phase 4 任务 4.1，计划中，未执行。

**需要做**：
- 添加 `zstd` crate 实现压缩
- 添加 `chacha20` crate 实现加密
- 密钥派生自 argon2 + salt
- 加密/压缩后的 content 存储

### 2.2 可选的加密密钥管理

**问题**：加密后的密钥如何安全存储？当前密码通过 CLI 参数明文传入，不安全。

**可能方案**：
- 环境变量
- 密钥文件
- 系统密钥链（Windows Credential Manager / macOS Keychain）

### 2.3 大文件处理

**问题**：当前实现全量读写，没有流式处理。大 Cluster（>100MB）可能导致内存溢出。

**可能方案**：
- 分块存储
- 惰性加载
- mmap 内存映射

## 三、共享与合并问题

### 3.1 跨 Cluster 引用

**问题**：Cluster A 的节点如何引用 Cluster B 的节点？

**当前状态**：未实现。每个 Cluster 完全独立，无法跨 Cluster 引用。

**可能方案**：
- 引用 ID + 文件路径：`cluster://path/to/file.stz#node_id`
- 共享节点注册表
- 惰性加载

### 3.2 三路合并

**问题**：当前 Merge 是"两路"（源 vs 目标），缺少共同祖先（common ancestor）。

**可能导致**：合并结果不准确，丢失一些变更。

**可能方案**：
- 在 Cluster 元数据中存储父 Cluster 的哈希
- 三路合并算法（类似 Git 的 merge-base）

### 3.3 惰性克隆

**问题**：当前 Clone 是全量深拷贝，O(n) 内存和时间。大 Cluster 克隆成本高。

**可能方案**：
- 写时复制（Copy-on-Write）
- 引用计数
- 共享未修改节点

### 3.4 合并时密码验证

**问题**：源 Cluster 有密码时，是否要求验证密码才能合并？当前未实现。

## 四、查询与算法问题

### 4.1 路径查询索引

**问题**：长路径查询（>100 节点）的 BFS 效率可能不足。

**可能方案**：
- 双向 BFS（从起点和终点同时搜索）
- 节点标签索引
- 关系类型索引

### 4.2 Impact 查询的精度

**问题**：当前 impact 查询是简单反向 BFS，没有考虑边类型和深度限制。

**改进方向**：
- 按关系类型过滤
- 最大深度限制
- 加权影响评分

### 4.3 图的一致性检查

**问题**：当前没有机制检测图的一致性（如循环依赖、孤立节点）。

**当前状态**：`health` 方法可以检测孤立节点和汇/源节点，但不够全面。

**改进方向**：
- 循环检测（DFS）
- 拓扑排序
- 完整性检查

## 七、官网问题

### 7.1 Google Fonts 加载

**问题**：Instrument Serif 和 DM Sans 通过 Google Fonts 加载。在中国大陆可能被墙。

**缓解**：使用 `font-display: swap`，回退字体为 Georgia + system-ui + monospace。

### 7.2 自定义域名

**问题**：如果需要自定义域名，需要配置 DNS 和 GitHub Pages 设置。

### 7.3 SEO

**问题**：单页应用对 SEO 不友好。需要添加 Open Graph 标签、结构化数据、sitemap。

**当前状态**：基本的 OG 标签已设置，但 sitemap 和结构化数据未实现。
