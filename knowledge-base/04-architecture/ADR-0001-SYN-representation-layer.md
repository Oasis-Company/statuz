# ADR-0001 · SYN 定位于表征层（Representation Layer）

> **状态**：Accepted（用户裁决，2026-08-21）
> **决策人**：Dr. Ceaserzhao（用户）· 校准：TRAE agent
> **影响对象**：SYN 机制归属、Syn 类型分布、`syn`/`niche` crate 定位

---

## 决策

**SYN（方向共创/升级机制）定位于 Statuz 的表征层（Representation Layer），而非内核（Kernel）。**

配套含义：
- **内核层**只负责"纯粹拓扑"：图、五个查询、存储。不承载语义解读或方向机制。
- **表征层**负责"语义 + 方向 + 释放"：把拓扑翻译成 agent 可消费的状态，SYN 的方向载子、共创裁决、不确定性升级阀都住在这里。
- 存量 `types.rs` 里的 `SynProposal/SynOption/SynStatus` 属于**表征层的领域类型**，理论上应从内核迁出或在其上重述——但**迁移动作待执行计划 O4 裁决后再动**，本 ADR 只定归属，不前移代码。

## 背景

SYN 在对话中被多次重新定义：从"变更决策人"→"不确定性升级阀"→"归还方向控制权"→"方向共创机制"。最终裁定 SYN **裁方向、不裁动作**，且"引导/纠偏"是同一核心的两种触发。

这一性质决定了它**不是内核算法**——方向、意图、共创、升级都是"关于拓扑的意义层"活动，恰是表征层的本职。若把它留在内核，会让内核承担它承诺不承担的"语义主见"，违背 AGENTS.md 的"内核只管纯拓扑"精神。

## 备选与舍弃

- **留在内核**：舍弃。违背"内核零语义"边界，且让纯拓扑层背上方向机制复杂度。
- **并入 niche**：审慎。niche 暂为占位、定位未固，SYN 可与其相邻但不等同——SYN 偏"人 机机制"，niche 偏"语义解读"。本 ADR 只定"表征层"，不强行绑定某 crate。

## 影响

| 面 | 影响 |
|---|---|
| `types.rs` 存量 Syn 类型 | 归属确认为"表征层领域类型"，迁移待 O4 |
| `syn-execution-plan.md` | 概念锚点新增"SYN 定在表征层"；方向载子是表征层实体 |
| `niche`/`syn` crate | 定位回归表征层讨论，MD 计划执行到再定 |
| BRANDING_DESK | 不涉及（对外只说愿景） |
